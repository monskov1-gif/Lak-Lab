# Lak Translator Lab

A static, browser-based Russian–Lak translation research workspace.

## Publish with GitHub Pages
1. Create a new **public** repository named `lak-translator-lab` on GitHub.
2. Upload `index.html` and `README.md` to the repository root (the top level, not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to finish. The URL will be `https://YOUR-USERNAME.github.io/lak-translator-lab/`.

This is a static HTML site and does not need a build step, API key, or server.
